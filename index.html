ALGORITHM GUIDE

How the greedy method works

01

Sort by profit

Arrange all jobs from highest profit to lowest profit.

02

Find a free slot

For each job, check the latest free slot on or before its deadline.

03

Calculate profit

Allocate the job if a slot is available. Add its profit to the total.

Why latest slot? Placing a job as late as possible keeps earlier slots free for jobs with smaller deadlines.

C PROGRAMMING

Core C implementation

The complete beginner-friendly C program is included in job_allocation.c in this project folder.

1. Sort jobs by descending profit.
2. For each job:
   Check slots from deadline down to 1.
   If a slot is free, allocate the job.
3. Add the selected job's profit.
4. Display the allocated jobs and total profit.
